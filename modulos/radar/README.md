# Radar

Cada domingo por la tarde, un resumen de lo que pasó en IA esa semana, filtrado por lo que sirve para mis temas y lo que se puede usar gratis. Sirve para planear la semana.

## Qué trae
1. De 5 a 8 novedades de los últimos 7 días, verificadas en su fuente original. Cada una dice qué es, qué cambió, si es gratis y su letra pequeña, y cómo aplicarla.
2. **Para probar esta semana:** una sola herramienta, con pasos para probarla en menos de una hora.
3. **Idea de servicio:** algo que se le podría vender a un negocio usando lo del radar.

## Cómo se genera
Una tarea programada de Claude corre los domingos a las 6:45 PM en la nube y entrega una página de una columna, pensada para el celular, con modo claro y oscuro. El texto que recibe la tarea está en [prompt.ejemplo.md](prompt.ejemplo.md).
